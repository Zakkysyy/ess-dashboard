# 🌿 Smart Environmental Sensing System (ESS) - Live Dashboard

**Bengkel Mekatronika Politeknik Kota Malang (POLTEKOM)**

Live Web Monitoring Dashboard for Real-time Temperature, Humidity, MQ-7 (Carbon Monoxide), and MQ-2 (Smoke/LPG) sensor telemetry streaming directly from Firebase Realtime Database.
